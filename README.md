# ESP32-C6 Clock + Weather ⏰🌡️

Объединение двух проектов на одной плате **Waveshare ESP32-C6-Zero**:
настольные Wi-Fi-часы с OLED SSD1322 **и** метеостанция на BMP280 — со всем функционалом обоих.

## ✨ Возможности

**Часы (SSD1322 256×64):**
- Крупные часы реального времени, авто-переход зима/лето по POSIX-`TZ`
- Авто/ручная яркость, полное отключение дисплея
- Стильный веб-дашборд (WebSocket, live), светлая/тёмная тема, сворачиваемые блоки
- Секундомер с кругами: формат `MM:SS.mmm` → `HH:MM:SS` после часа, синхронизация с устройством, «геройский» режим при запуске
- REST API + WebSocket, `clock.local` по mDNS

**Метеостанция (BMP280):**
- Температура, давление (гПа/мм.рт.ст.), высота, QNH, плотность воздуха
- Тренд давления и простой прогноз (☀️/⛅/🌧️)
- Мониторинг батареи 18650 (делитель + кривая разряда Li-ion)
- MQTT + Home Assistant Discovery, WS2812 статус-LED

Температура и давление также выводятся в нижней строке OLED.

**Экран OLED (единая раскладка):** время крупно сверху, снизу строка «день · температура · давление» слева и иконка батареи с процентами справа (батарея показывается только при питании от 18650; при USB — скрыта). В режиме секундомера — крупный отсчёт сверху и та же строка погоды/батареи снизу (маркер `II` на паузе).

## 🛠️ Карта пинов ESP32-C6-Zero

| Узел | Пины |
|------|------|
| OLED SSD1322 (HW SPI) | CLK 18 · DIN 19 · CS 20 · DC 21 · RST 22 |
| BMP280 (I²C) | SDA 4 · SCL 5 (addr 0x76) |
| Батарея 18650 (ADC) | GPIO2 (делитель 100к/100к) |
| WS2812 RGB (встроенный) | GPIO8 |

У C6-Zero пины **двух сортов**, и это определяет всю разводку:

- **Боковые кастеллированные** — сюда паяется гребёнка:
  левый ряд `5V GND 3V3 | 0 1 2 3 4 5`, правый ряд `TX RX | 14 15 18 19 20 21 22`
- **Пятачки на обратной стороне** — провод придётся тянуть под платой:
  `6 7 8 9 12 13 23`

Поэтому OLED разведён на правый боковой ряд (18…22) одним шлейфом, а не на 6/7: SPI — самые быстрые линии в схеме, тянуть их с изнанки не стоит. Слева остаются BMP280 (4, 5) и батарея (2).

Занято намертво: **8** (WS2812), **9** (кнопка BOOT), **12/13** (USB D-/D+, у нас USB CDC), **TX/RX** (UART0). Strapping-пины C6 (**4, 5, 8, 9, 15**) дисплеем не занимать. ADC есть **только на GPIO0…6** — отсюда батарея на 2. Свободный резерв: `0, 1, 3, 14` сбоку и `6, 7, 23` на изнанке.

Все пины меняются в `src/config.h`.

## 🚀 Сборка

Платформа **pioarduino** (официальная `espressif32` не поддерживает C6 — нужен core 3.x):

```bash
# 1. В src/config.h впиши WIFI_SSID / WIFI_PASSWORD (только 2.4 ГГц) и TZ_INFO
# 2. Собрать и прошить
pio run -t upload
pio device monitor      # затем нажми RST
```

`build_flags` уже включают USB CDC (иначе Serial на C6-Zero пуст). Если OLED ещё не подпаян — поставь `#define HAS_DISPLAY 0`, чтобы не гонять SPI вслепую.

## 🌐 API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Дашборд |
| GET | `/api/stats` | Полное состояние (часы + погода + батарея) |
| GET | `/api/time` | Время/дата/uptime |
| GET | `/api/weather` | Только метео + батарея (temp, pressure, QNH, altitude, trend, forecast) |
| POST | `/api/brightness` | `value=0..100` или `auto=1` |
| POST | `/api/power` | `on=1` / `on=0` |
| POST | `/api/reboot` | Перезагрузка |

WebSocket `ws://<IP>:81` — секундомер: `sw:start` / `sw:pause` / `sw:reset`.

## 🏠 MQTT / Home Assistant

Отключён по умолчанию (`MQTT_ENABLED false` в `config.h`). При включении публикует температуру, давление, высоту и батарею + авторегистрацию сущностей через MQTT Discovery (топики `clock/weather/*`).

## 💡 LED-индикация (WS2812 GPIO8)

Синий — старт/подключение · зелёный мигок — норма · жёлтый мигок — АКБ разряжена · красный — ошибка датчика.

## 📋 Примечания

- Датчик температуры BMP280 даёт **честную температуру воздуха** (в отличие от встроенного датчика кристалла C6, который завышает).
- CPU зафиксирован на 80 МГц + Wi-Fi modem-sleep — меньше нагрев/потребление (актуально при питании от 18650).
- Если MQTT выключен, его код не компилируется (нулевой оверхед).
