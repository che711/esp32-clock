# esp32-clock

Часы + метеостанция на ESP32-C6-Zero: SSD1322 256×64 по SPI, BMP280 по I2C,
питание от 18650 через TP4056. Веб-дашборд отдаётся самим устройством.

## Команды

```bash
pio run -e esp32c6            # сборка прошивки
pio run -e esp32c6 -t upload  # прошить (порт обычно /dev/ttyACM0)
pio test -e native            # 146 тестов чистой логики, без железа
pio device monitor            # 115200, с декодером бэктрейсов
```

Сборка обязана оставаться зелёной вместе с тестами: `pio run` и `pio test`
после любой правки.

## Устройство кода

- `*_calc.h` — **чистая логика без Arduino**: пересчёт напряжения в проценты,
  гамма яркости, выбор режима питания, прогноз по барометру. Собирается
  нативно и покрыта тестами в `test/test_native/`. Новую расчётную логику
  писать сюда и покрывать тестом, а не прятать в `.cpp`.
- `*.cpp` — работа с железом и сетью, тестами не покрыта.
- `app.h` — состояние, которым владеет `main.cpp`; остальные модули читают.
- `config.h` — все настройки и пороги, каждый с комментарием «почему столько».
- `web/index.html` — **единственный источник** веб-интерфейса. При сборке
  гзипуется в массив (`scripts/gen_web_ui.py`), ETag = хеш содержимого.
  Генерируемый заголовок руками не трогать.

## Соглашения

- Комментарии на русском и объясняют **почему**, а не что делает строка.
  Особенно ценно: какой вариант пробовали до этого и чем он оказался плох.
- Числовые пороги не появляются из воздуха — рядом обоснование или замер.
- README.md — не справочник по API, а рассказ о принятых решениях. Правки
  в поведении отражать там же.

## Электрика: измеренное

Замерено лабораторным блоком питания вместо банки, при 4.2 В:

| Состояние | Ток |
| --- | --- |
| Экран выключен | 60–80 мА |
| Экран включён, яркость 2 % (свечения нет) | 100–120 мА |
| Экран на яркости около полной | 160–180 мА |

Отсюда: чип с радио — 60–80 мА (самая крупная статья, процессор не спит),
обвязка панели — ~40 мА, свечение — до 60 мА. Автономность на 18650 сейчас
около суток. Подробности и раскладка — в README, раздел «Что сколько ест».
